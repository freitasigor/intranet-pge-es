# Intranet Project (Orchard CMS) 🇧🇷 🇺🇸

## 🇧🇷 Versão em Português

Projeto desenvolvido como parte do meu portfólio de **Análise e Desenvolvimento de Sistemas**. Trata-se de uma Intranet funcional construída sobre o framework Orchard CMS.

### 🚀 Tecnologias Utilizadas (Tech Stack)
* **Framework:** Orchard CMS 1.10 (ASP.NET MVC)
* **Linguagem:** C#
* **Banco de Dados:** SQL Server Compact (SQL CE)
* **IDE:** Visual Studio 2022

### 🎨 Customização e Fluxo de Trabalho
* **Papel do Visual Studio:** Utilizado apenas para compilar e rodar o núcleo da aplicação. Nenhuma codificação backend foi necessária para o visual do site.
* **Desenvolvimento Front-end:** Todas as páginas, layouts e scripts foram criados diretamente dentro do **Painel Administrativo do Orchard**.
* **Tecnologias:** HTML, CSS e JavaScript (implementados via dashboard).

### 🏗️ Infraestrutura e Deploy
* **Hospedagem:** O sistema foi implantado em uma **Máquina Virtual (VM)** dedicada na infraestrutura corporativa da PGE-ES.
* **Segurança:** Ambiente protegido com **Certificados SSL** confiáveis (HTTPS), garantindo criptografia de ponta a ponta.
* **Rede:** Configurado com redirecionamentos de DNS e roteamento interno para acesso corporativo otimizado.

### 🐰 Easter Egg
* **Curiosidade:** Se você for curioso e abrir o código-fonte, encontrará uma surpresa escondida logo nas primeiras linhas de código! 👀

### 🛠️ Como Rodar o Projeto (Local)
1.  Faça o **Clone** deste repositório para sua máquina local.
2.  Abra o arquivo de solução chamado **`INTRANET ORCHARD FUNCIONANDO.sln`** no Visual Studio.
3.  Compile e rode o projeto (Aperte `F5`).
4.  **Configuração:** Na primeira execução, crie um **Usuário Administrador**.
5.  Após logar, acesse o Painel Administrativo para visualizar ou editar as customizações.

## 🇺🇸 English Version

Project developed as part of my portfolio, focusing on **Systems Analysis and Development**. This is a functional Intranet system built on top of the robust Orchard CMS framework.

### 🚀 Tech Stack
* **Framework:** Orchard CMS 1.10 (ASP.NET MVC)
* **Language:** C#
* **Database:** SQL Server Compact (SQL CE)
* **IDE:** Visual Studio 2022

### 🎨 Customization & Workflow
* **Visual Studio Role:** Used exclusively to build and run the application core. NO backend coding was required for the site's visuals.
* **Frontend Development:** All pages, layouts, and scripts were created directly inside the **Orchard Admin Panel**.
* **Technologies:** HTML, CSS, and JavaScript (implemented via the dashboard).

### 🏗️ Infrastructure & Deployment
* **Hosting:** Deployed on a dedicated **Virtual Machine (VM)** within the PGE-ES (State Attorney General's Office) enterprise infrastructure.
* **Security:** Secured with trusted **SSL Certificates (HTTPS)** to ensure encrypted and safe connections.
* **Network:** Configured with internal DNS redirections and proper network routing for seamless corporate access.

### 🐰 Easter Egg
* **Fun Fact:** If you are curious enough to open the source code, you will find a hidden surprise right within the first few lines of code! 👀

### 🛠️ How to Run
1.  **Clone** this repository to your local machine.
2.  Open the solution file named **`INTRANET ORCHARD FUNCIONANDO.sln`** using Visual Studio.
3.  Build and Run the project (Press `F5`).
4.  **Setup:** On the first run, create an **Admin User** to access the dashboard.
5.  After logging in, use the Admin Panel to see/edit customizations.
